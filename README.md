# ap-handbook
Interaktives Handbuch für die Anfängerkurse im Labor (AP-I, AP-II, AP-EDU). Erstellt mit Jupyter Book, versionskontrolliert auf GitHub und mit ILIAS für Zeitpläne und Benotungen verknüpft. Enthält Hintergrundtheorie, Experimentanleitungen und reproduzierbare Analyse-Tutorials, die auf Binder ausgeführt werden können.
